**エピック3: 推薦の管理**

*   **ユーザーストーリー3.1: 推薦へのフィードバック（興味なし）**
    *   **説明:** ユーザーとして、興味のない推薦映画を「興味なし」とマークしたい。
    *   **受け入れ基準:**
        *   各推薦映画に「興味なし」ボタンが表示される。
        *   ボタンを押すと、その映画は推薦リストから非表示になる。
        *   「興味なし」とマークされた映画の情報は、将来の推薦精度向上のために利用される（例：同じ監督や俳優の映画の推薦度を下げる）。
        *   間違えて押した場合に備え、「元に戻す」オプションが一時的に表示される。

*   **ユーザーストーリー3.2: ウォッチリストへの追加**
    *   **説明:** ユーザーとして、興味のある推薦映画をアプリ内のウォッチリストに追加したい。
    *   **受け入れ基準:**
        *   各推薦映画に「ウォッチリストに追加」ボタンが表示される。
        *   ボタンを押すと、その映画は専用のウォッチリストページに追加される。
        *   ウォッチリストページでは、追加した映画を一覧で確認できる。
        *   ウォッチリストから映画を削除することもできる。

*   **ユーザーストーリー3.3: 推薦理由の確認**
    *   **説明:** ユーザーとして、なぜその映画が推薦されたのか、具体的な理由を知りたい。
    *   **受け入れ基準:**
        *   推薦リストの各映画に「なぜこれを推薦？」のようなリンクやアイコンが表示される。
        *   クリックすると、「Amazonで購入した『[商品名]』に関連しています」といった、より詳細な推薦理由が表示される。
